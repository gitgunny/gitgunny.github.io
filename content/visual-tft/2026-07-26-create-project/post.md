## 프로젝트 생성

프로젝트를 생성합니다.

1. File 메뉴 → New Project
2. Location → Name, Path → 프로젝트 이름 입력 및 경로 설정
3. Device Type → Series, Type → TFT 시리즈 및 모델 선택
4. OK 생성

> ![Note](https://cdn.jsdelivr.net/gh/gitgunny/gitgunny.github.io@main/assets/icons/note.svg)
>
> Device Type 설정은 프로젝트 생성 이후에도 변경할 수 있습니다.
