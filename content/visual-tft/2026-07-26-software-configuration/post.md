## Visual TFT 설치

본 문서는 Visual TFT 소프트웨어 설치 후 한글 글꼴 추가하는 방법에 대해 설명합니다.

### 다운로드 및 설치

Visual TFT 소프트웨어를 [다운로드](https://www.gz-dc.com/category/typeid/8)하고 설치합니다.

> ![Important](https://cdn.jsdelivr.net/gh/gitgunny/gitgunny.github.io@main/assets/icons/important.svg)
>
> 본 문서는 영문(English) 설치로 진행합니다.
> 설치 경로는 운영체제가 설치된 드라이버(예 C:\\)에 설치하는 것을 권장합니다.

> ![Note](https://cdn.jsdelivr.net/gh/gitgunny/gitgunny.github.io@main/assets/icons/note.svg)
>
> Visual TFT 인터페이스에 대한 설명은 [여기](https://doc.gz-dc.com/QuickStart/03_PCsoft.html)에서 볼 수 있습니다.

### 한글 글꼴 추가

글꼴을 [다운로드](https://hangeul.naver.com/font)하고 Visual TFT 글꼴에 추가합니다.

> ![Important](https://cdn.jsdelivr.net/gh/gitgunny/gitgunny.github.io@main/assets/icons/important.svg)
>
> 한글이 포함된 글꼴을 추가해야 TFT 화면에 한글을 띄울 수 있습니다.

1. 다운로드 받은 글꼴 중 사용할 글꼴(.tft)을 Visual TFT 글꼴 폴더(\\VisualTFT\\font\\truefont)에 추가합니다.
2. VisualTFT 메뉴 → Tool → Font Configuration 열기
3. Default Font → 사용할 글꼴 지정
4. Code Set → UTF8 변경
5. Save 저장
> ![Note](https://cdn.jsdelivr.net/gh/gitgunny/gitgunny.github.io@main/assets/icons/note.svg)
>
> 추후 한글 인코딩 호환을 위해 Code Set을 UTF8로 변경합니다.
> Font File 콤보 박스를 선택하지 않으면 Default Font 설정을 따라갑니다.
